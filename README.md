# SmartPark TRACE

**Data Structures & Algorithms semester project** — explainable multi-level parking management, routing and allocation.

## Planned scope

Multi-building/multi-floor vehicle allocation, compatible slots, graph-based route finding and blocked-lane recovery, priority waiting, tree-based indexes, parking history, hourly billing and operator interfaces.

**Status:** Project repository initialized; implementation has not been uploaded or verified here. This README is an overview, not a claim of completed functionality.
